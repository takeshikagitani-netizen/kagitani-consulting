## 0. エグゼクティブサマリー

- 大栗さんから、**錬金堂のフランチャイジー（加盟店）を続けるのではなく、自身がフランチャイズ本部（フランチャイザー）を立ち上げる**という、事業の根幹に関わる大きな舵取りの相談があった。
- これは「店舗を上手く回す力（運営力）」から「**事業の仕組みを作って売り・支える力（本部機能）**」への、**コアコンピタンスの転換**を意味する。求められる能力・投資・時間軸がまったく異なる。
- 最大のリスクは **錬金堂とのFC契約上の制約（競業避止・ノウハウ帰属・契約期間）**。ここを潰さない限り、構想は法務的に成立しない可能性がある。**Phase 0（法務デューデリ）を最優先**とする。
- 大栗さんの「複雑な家庭環境」「スタッフへの強い思い」は、ソフトな背景情報ではなく**意思決定を左右する戦略変数**として扱う。特にスタッフへの思いは、本部化（＝教育・支援が本業）と**相性が良い強み**になり得る。
- 鍵谷コンサルとしては、いきなり本部設計に飛びつかず、**①勝ちパターンの数値証明 → ②仕組み化 → ③パイロット加盟 → ④拡大**の順で伴走するのが定石。本メモはその初期設計。

- 既存スタッフは、本部化において **研修トレーナー・スーパーバイザー（SV）・モデル店長** という形で「資産」に転換できる。
- 留意点: 「全員の雇用維持」を事業判断より優先すると本部の収益性が崩れる。**思いを活かす配置**と**冷徹な事業性判断**を分けて設計する。

## 2. 戦略論点：フランチャイジー → フランチャイザー化

### 2-1. 何が根本的に変わるか
| | 加盟店（現状） | 本部（目指す姿） |
|---|---|---|
| 商品 | 中古品の買取・販売 | **「儲かる仕組み」と「ブランド」を加盟店に売る** |
| 収益源 | 商品粗利 | 加盟金・ロイヤリティ・物流/換金マージン・指導料 |
| コア能力 | 店舗運営・査定 | 仕組み化・加盟店開発・SV・ブランド管理・法務 |
| 顧客 | 売りたい人/買いたい人 | **加盟したい事業者** |
| 失敗時の影響 | 自店のみ | 全加盟店・ブランド全体に波及 |

→ 「現場が上手い」ことと「本部が務まる」ことは別スキル。**ここを大栗さん自身が腹落ちしているかが最初の関門。**

### 2-2. リユース・買取業界でのFC本部の現実（一般論）
- リユース市場は拡大基調（二次流通の一般化・物価高・SDGs）。買取専門店FCは参入が活発な「レッドオーシャン化しつつある成長市場」。
- 既存の買取FC本部が複数存在する中で、新規本部が選ばれるには **明確な差別化** が必須:
  - 査定・教育ノウハウの再現性（誰でも一定品質で査定できる仕組み）
  - **販路／在庫の換金経路**（買い取った在庫をどこで高く現金化するか＝加盟店の生命線）
  - 集客モデル（出張買取・店舗・EC・広告の型）
  - ブランドと世界観
- **[要確認]** 大栗さん（および錬金堂で培った経験）の中で、上記のどれを「自分の武器」と認識しているか。

確認すべき契約条項（**[要確認]**）:
1. **競業避止義務** — 契約期間中／契約終了後の一定期間、同業（買取・リユース）の事業や**競合FC本部の運営**が禁止されていないか。範囲（地域・期間・業態）は。
2. **ノウハウ・知的財産の帰属** — 錬金堂から受けたマニュアル・査定基準・顧客リスト・販路を、自分の本部に流用することは契約違反にならないか（→ 原則、流用は不可前提で「自前のノウハウ」を作る必要）。
3. **契約期間・中途解約条件・違約金**。
4. **商標・屋号** — 「錬金堂」関連の名称・看板は当然使用不可。新ブランドの**商標調査・登録**が必要。

→ 結論の出し方: まず契約書を弁護士（FC・フランチャイズに強い専門家）とレビュー。**「いつから・どの形なら適法に動けるか」のクリーンな線引き**を確定してから次へ。

## 4. 推奨ロードマップ（仮説）

> 原則：**本部化は「直営で勝ちパターンを数値で証明してから」**。再現性のないモデルをFC化すると加盟店が失敗し、本部ごと崩れる。

### Phase 0 — 前提固め（〜1〜2ヶ月）
- 錬金堂契約の法務デューデリ（§3）。
- 大栗さん個人の意思・家庭・資金・時間軸の確定（§1）。
- 「自前のノウハウ／差別化の核」の棚卸し（§2-2）。
- ゴール: **「やる／やらない／いつから」の意思決定**。

### Phase 1 — 直営モデルの確立と数値化（〜6〜12ヶ月）
- 自前ブランドで直営1〜数店を運営し、**収益モデルの再現性を数値で証明**（買取単価・粗利率・在庫回転・換金率・1店あたり損益分岐・回収期間）。
- マニュアル化を前提に、全業務を**「言語化・標準化」**しながら回す。
- スタッフをモデル店長／トレーナー候補として育成。

### Phase 2 — 本部機能の設計（Phase 1と一部並行）
- ブランド構築・**商標登録**、世界観・ストーリー。
- 運営マニュアル／査定基準／研修プログラム／SV体制。
- **法定開示書面（情報開示書面）** とFC契約書の整備（中小小売商業振興法・FC関連の説明義務に対応）。
- 加盟金・ロイヤリティ・物流/換金マージンの**収益設計**（本部が儲かり、かつ加盟店も儲かる水準）。
- 在庫の**換金・販路インフラ**の本部集約（加盟店の最大の価値提供）。

### Phase 3 — パイロット加盟（1号店）
- 信頼できる相手（理想は意欲ある既存スタッフ／身内）で1号加盟店を立ち上げ、**本部支援フローを実地で検証・修正**。

### Phase 4 — 加盟店募集・拡大
- 加盟店開発（募集チャネル・説明会・審査基準）。
- SV体制でスケール。品質とブランドを守る統制。

## 8. 重要な留意・リスク（率直な所見）

- **「成功した加盟店オーナーが、必ずしも良い本部になれるわけではない」** — これは業界の典型的な落とし穴。現場の名選手が名監督とは限らない。
- 錬金堂契約の競業避止次第では、**構想そのものの時期・形を変える必要**がある。希望的観測で進めない。
- リユース買取FCは既に競合多数。**「なぜ大栗さんの本部に加盟するのか」の一言**が言えるまで、本部化は走らせない。
- 一方で、大栗さんの**人を大切にする経営観**は、加盟店との長期信頼が要のFCビジネスにおいて、模倣されにくい強い差別化資産になり得る。ここは積極的に活かす。
