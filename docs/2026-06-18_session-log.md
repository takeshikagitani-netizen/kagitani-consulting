## 1. 依頼の背景

鍵谷が大栗さんと面談を実施。その内容を踏まえ、今後の展開を精査する依頼。面談で得られた主なポイント:

- 大栗さんの**複雑な家庭環境**を深く知ることができた。
- **スタッフに対する強い思い**を知ることができた。
- 錬金堂でのフランチャイズ（加盟店）を続けるのではなく、**大栗さん自身がフランチャイズを立ち上げる**という、大きな舵取りの話が出た。鍵谷に舵取りを依頼したいという文脈。

| 確認項目 | 鍵谷の回答 |

## 3. 精査の結論（要約）

詳細は `docs/2026-06-18_大栗さん面談フォローアップ.md`。骨子は以下。

1. 本件は規模拡大ではなく**「加盟店運営力 → 本部機能」への業態転換**。本人の腹落ちが第一関門。
2. **最優先は錬金堂FC契約の法務デューデリ**（競業避止・ノウハウ/販路/顧客の帰属・契約期間・商標）。ここが未確認だと構想は成立しない可能性。
3. ロードマップ: Phase0 前提固め → Phase1 直営で勝ちパターンの数値証明 → Phase2 本部機能設計 → Phase3 パイロット加盟 → Phase4 拡大。
4. 大栗さんの**スタッフへの思い**は、教育・支援が本業のFC本部と相性が良く、差別化資産に転換可能。**家庭環境**は時間軸・リスク設計の前提変数として尊重。
5. 鍵谷コンサルの**関与範囲・報酬モデル**を早期にすり合わせる必要。
